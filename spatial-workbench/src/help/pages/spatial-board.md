## Sketch an idea

Open **Spatial Board** to use the Excalidraw canvas. Draw shapes, connect them with arrows, and add labels to describe a system or plan. Use the canvas controls to pan, zoom, and adjust the view.

The board is shared through the companion server. A browser copy provides a fallback when the server is unavailable; it does not mean every edit has been saved remotely.

## Work with an agent

Browser-local visual tools can use the shared board endpoints. A full Hermes Gateway agent needs its own HTTP tools configured to reach those endpoints. Merely choosing Gateway does not register board tools in Hermes.

Tell the agent what should change and inspect the board afterward. Shared-board operations can affect other browsers using the same installation.

## Keep a record

Use the canvas export controls for a portable diagram when needed. Keep the editable scene and relevant explanations in your normal backup process. If a diagram appears missing, confirm you are using the same installation and that the companion API is reachable before replacing the board.

Use [Wiki & notes](#help/wiki) for the written decisions behind a diagram and [Projects](#help/projects) for exported files.
